Fast Pizza: Pizza Ordering Application Developed a modern pizza ordering platform where users can browse the menu, customize their orders, and track their delivery status. Implemented dynamic menu loading with URL parameters for fetching and displaying pizza details. Integrated a real-time order tracking system, a cart management system, and a responsive homepage featuring a hero section, menu search, popular pizzas, and special offers. Utilized Redux Toolkit for state management and Tailwind CSS for styling.

Technologies: JavaScript, React.js, Redux Toolkit, Vite, Tailwind CSS Key Features:

Dynamic Menu Loading: Implemented dynamic loading to fetch and display pizza details based on URL parameters.
State Management: Utilized Redux Toolkit to manage global state for menu items, cart, and user interactions.
Real-Time Order Tracking: Integrated a real-time order tracking system for delivery status updates.
Responsive Design: Designed a responsive homepage with a hero section, menu search, popular pizzas, and special offers.
API Integration: Fetched menu and order data from a backend API using asynchronous functions.
