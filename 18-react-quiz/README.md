# React Quiz Application

Developed an interactive quiz application to test users' knowledge of React. The application features dynamic question loading, state management, a countdown timer, progress tracking, and responsive design. Implemented error handling and highscore tracking to enhance user experience.

Technologies: JavaScript, React, useReducer hook, CSS, JSON Server, HTML

Key Features:

Dynamic Question Loading: Fetched questions from a JSON server for easy updates and scalability.
State Management: Utilized React's useReducer hook to manage various states such as loading, error, ready, active, and finished.
Timer: Integrated a countdown timer for each question to add a challenge.
Progress Tracking: Displayed current question, total questions, and points scored.
Responsive Design: Ensured the application is visually appealing across different devices.
Error Handling: Displayed appropriate error messages for data fetching issues.
Highscore Tracking: Tracked and displayed users' high scores at the end of the quiz.
