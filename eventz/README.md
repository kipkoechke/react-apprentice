**PERSONAL TECHNICAL PROJECTS**

**Eventz: Event Website**
Developed a modern event booking platform where users can search for local events, view event details, and purchase tickets for individuals or groups. Implemented Next.js dynamic routing with URL parameters for fetching and displaying event details. Integrated a real-time countdown for event start times, a ticketing system, and a responsive homepage featuring a hero section, event search, upcoming events, and recommended events. Utilized Context API for state management and Tailwind CSS for styling.

- **Technologies:** TypeScript, React.js, useMemo hook, Context API, Next.js, Tailwind CSS, ShadCN

- **Key Features:**
  - **Dynamic Routing:** Implemented Next.js dynamic routing to fetch and display event details based on URL parameters.
  - **State Management:** Utilized Context API to manage global state for events, filters, and user interactions.
  - **Real-Time Countdown:** Integrated a real-time countdown timer for event start times.
  - **Responsive Design:** Designed a responsive homepage with a hero section, event search, upcoming events, and recommended events.
  - **API Integration:** Fetched event data from a local JSON file placed in the public folder and handled API routes using Next.js.
